# Chat-management-bot-and-AI-assistant
pythash bot is a full-featured, open-source Telegram group manager: AI Q&amp;A, a credit system, pluggable AI providers (FreeModel, Groq, Gemini),moderation(warn/ban/mute, word filters, link control), anti-spam, join verification, a custom personality, automatic database backups to a channel, and a donation section all configurable from inside the bot.
